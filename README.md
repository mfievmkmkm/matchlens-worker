# MatchLens Worker

API и вычислительный worker для анализа футбольных видео. Сервис принимает матч, запускает
сменный CV-анализатор и возвращает радар, наблюдаемые показатели игрока и HTML-отчёт.

Сервис принципиально не генерирует статистику через LLM. Если детектор не настроен или игрок
не виден, задание завершается с понятной ошибкой вместо выдуманных километров и передач.

## API

- `GET /health`
- `POST /v1/matches` с заголовком `x-api-key`
- `GET /v1/matches/{id}`
- `POST /v1/matches/{id}/target` — выбрать tracker ID после превью
- `POST /v1/uploads` — безопасно принять видео от Telegram-бота
- публичные YouTube-ссылки скачиваются через `yt-dlp`; плейлисты запрещены, размер ограничен
- `GET /v1/results/{id}/report.html`

Пример задания:

```json
{
  "source": {"type": "url", "ref": "https://storage.example/match.mp4"},
  "target": {"player": "№7, синяя форма", "tracker_id": 7},
  "mode": "full",
  "outputs": ["annotated_video", "radar", "player_stats", "clips", "coach_report"]
}
```

`ANALYZER_COMMAND` — команда адаптера компьютерного зрения. В шаблоне доступны `{input}`,
`{output}` и `{tracks}`. Анализатор обязан записать нормализованный `tracks.json` с FPS,
координатами игроков и мяча на поле в метрах. Например:

```env
ANALYZER_COMMAND=python /opt/sports/adapter.py --input {input} --output {output} --tracks {tracks}
```

Для production используется GPU-образ с Roboflow Sports и тремя весами: детектор игроков,
детектор мяча и ключевые точки поля. SoccerNet GSR подключается вторым профилем для распознавания
номеров и повторной идентификации.

`Dockerfile.gpu` содержит зафиксированную версию Roboflow Sports, загрузку демонстрационных
весов и адаптер, создающий `tracks.json`, `preview.jpg` и `annotated.mp4`. Если tracker ID не
задан, первое прохождение останавливается на `awaiting_selection`: пользователь смотрит превью
с номерами треков и выбирает нужного футболиста без повторного анализа видео.

## Безопасность

- приватные и локальные адреса источников блокируются;
- размер загрузки ограничен;
- результаты защищены тем же API-ключом;
- исходники и веса не входят в GitHub;
- в статистику попадают только видимые и достаточно уверенные наблюдения.
